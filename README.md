# The Art of Clarity

Статический многостраничный сайт бренда The Art of Clarity / Nataliia Haidukevych.

## Локальный запуск

Откройте `index.html` напрямую или запустите любой статический HTTP-сервер в корне проекта.

## Страницы

- `index.html` — главная
- `executive.html` — Executive Advisory
- `products.html` — форматы сотрудничества
- `personal.html` — личные вопросы
- `about.html` — о Наталье
- `contact.html` — первый шаг и контакт
